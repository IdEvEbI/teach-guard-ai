# 提升建议

- **版本**：v0.1
- **用途**：把结构与概念观察收成可执行建议。不打分。

## 分栏

- `must_fix`：合格线，本段必须改。每一条都必须有 `clock` 与 `quote`（摘自用户提供的逐字稿）。没有摘句的条目不要输出。
- `nice_to_have`：水平线，锦上添花。可以没有摘句（例如时长观察），有摘句更好。
- `playback`：待回放确认。包括共屏画面、字号、光标、未截到的后半段、备课材料是否齐备、学员是否跟上，以及本段未覆盖的开场其余部分。

改法写老师下次可以怎么讲、共屏上怎么呈现。不要写「表达更清晰」一类套话。

## 输出

只返回一个 JSON 对象，不要 Markdown 围栏，不要解释：

```json

  "delivery": "学员听完应带走什么（一句话）。",
  "coverage": "本段实际覆盖了课型的哪一部分；stage_first 须写明是否只覆盖「学什么」。",
  "structure": {
    "modules": [
      {
        "title": "模块名",

    "how": "口头 How。",

  },
  "must_fix": [
    {
      "item": "缺口名称",

    }
```
