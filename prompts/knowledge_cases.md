# 概念与示例

- **版本**：v0.1
- **用途**：检查当段口头概念是否可懂、示例是否贴合主交付。不是全文纠错。

只评稿上能核对的内容：

1. 术语是否先通俗后专名。先甩专名、学员没有抓手时，可以写水平线或合格线（须有摘句）。
2. 示例是否服务当段主交付。阶段地图课里展开成完整算法推导，属于跑偏，不是「讲得细就是好」。
3. 疑似 ASR 听错（同音、近音、专名被听成别的词）单独列入 `asr_suspects`，**不要**写成老师的知识错误或口误合格线。报告里标明「疑似 ASR」。
4. 口误与 ASR 错词不是一回事。没有把握时写入待回放，不要写成必须改。
5. 无时间锚摘句，不得把概念问题写成合格线。
